How to Play Number Sequence Solver

  1. Press Start to begin the ten-question challenge.
  2. Study the number pattern shown on screen.
  3. Choose the number that should come next.
  4. Patterns include counting, doubling and increasing gaps.
  5. Earn 10 points for each correct answer.

Tip: Check how much each number changes by — the gap may grow or the numbers may multiply.
