How to Play What's Wrong?

  1. Press Start to view a scene made of several objects.
  2. One object does not fit the scene or breaks a simple rule.
  3. Tap the object you think is wrong.
  4. Read the explanation after each answer.
  5. Find the wrong item in ten different scenes.

Tip: Think about what belongs in the setting and what would be impossible there.
