How to Play Memory Match

  1. Choose Easy, Normal or Hard to set the number of pairs.
  2. Select any two cards to reveal their symbols.
  3. If the symbols match, the pair stays open. If not, they turn face down again.
  4. Remember where symbols are and match every pair in as few moves and as little time as possible.

Tip: Try to remember the position of each symbol as you reveal it.
