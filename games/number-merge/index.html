Use arrow keys or swipe to combine matching numbers. Reach 2048!

How to Play Number Merge

  1. Move the numbered tiles up, down, left or right.
  2. When two tiles with the same number meet, they merge into one tile with their values added together.
  3. Each move can add a new 2 or 4 tile to the board.
  4. Keep combining tiles, build your score and aim to make a 2048 tile.
  5. The game ends when there are no empty spaces and no possible merges.

Controls: Use the arrow keys, the direction buttons or swipe the board on a touch screen.
