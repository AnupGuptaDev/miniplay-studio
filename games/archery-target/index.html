How to Play Archery Target

  1. Start a round with five arrows.
  2. Adjust the aim slider for each shot.
  3. Release the arrow and see how close it lands to the centre.
  4. Closer shots earn more points: bullseye 10, inner ring 7, outer ring 3.
  5. Try to achieve the highest total score.

Tip: Small adjustments can make a big difference to your total.
