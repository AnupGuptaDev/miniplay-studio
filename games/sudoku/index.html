How to Play Sudoku

  1. Fill every row, column and 3×3 box with numbers 1–9.
  2. Each number can appear only once in each row, column and box.
  3. Tap an empty square, then tap a number below the board.
  4. Use Erase to clear a selected square. Complete the grid to win.

Tip: Look for rows, columns or boxes that already contain many numbers.
