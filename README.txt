MINIPLAY STUDIO STARTER

Files:
- index.html: responsive gaming portal homepage
- games/memory-match/index.html: your playable first game
- about.html, contact.html, privacy-policy.html: starter pages that need real content

TEST LOCALLY:
1. Unzip this folder.
2. Open index.html in Chrome.
3. Click Play game on Memory Match.
4. Test search, category filters, mobile layout and the game.

DEPLOY FREE WITH GITHUB PAGES:
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. miniplay-studio.
3. Upload the CONTENTS of this folder (index.html, games folder, and other pages) to the repository root.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for the Pages deployment to finish. The published address appears in Settings > Pages.
8. Test the homepage and /games/memory-match/ URL.

FREE HOSTING ALTERNATIVE:
Cloudflare Pages can deploy a Git repository. Create a Pages project, connect the GitHub repository, select the production branch, and leave the build command blank for this plain static HTML site; set the output directory to / (root), then deploy. Check current Cloudflare instructions if its dashboard labels change.

BEFORE ADSENSE:
- Replace all placeholder About, Contact and Privacy Policy text with accurate information.
- Add genuinely useful original game instructions, descriptions and other site content.
- Make sure every listed game is playable; remove or clearly label coming-soon cards.
- Test mobile usability, navigation, page speed and broken links.
- Do not put ads close to game controls or encourage ad clicks.
- AdSense approval and earnings are not guaranteed. Apply only after the site is complete and useful.
