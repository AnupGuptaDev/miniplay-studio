TEST LOCALLY:
1. Extract this project.
2. Open index.html in Chrome.
3. Open each game from the homepage.
4. Test keyboard and mobile touch controls where supported.

DEPLOY UPDATES:
If your GitHub repository is already connected to Cloudflare Pages:
1. Open the GitHub repository.
2. Choose Add file > Upload files.
3. Upload the updated index.html and the complete games folder (including all game folders).
4. Commit the changes to the main branch.
5. Cloudflare Pages should automatically deploy the new commit.
6. Check the deployment status in Cloudflare and test the live game links.

IMPORTANT:
- About, Contact and Privacy Policy pages are starter placeholders. Replace with accurate content before launch.
- These games are original simple implementations made for this project. Review and test them before public release.
- No ads, analytics, accounts, multiplayer servers or leaderboards are included yet.
- AdSense approval and earnings are not guaranteed. Build useful content and review Google's current policies before applying.
